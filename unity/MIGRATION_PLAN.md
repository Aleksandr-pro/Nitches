# План миграции Nitches Horizon на Unity

Godot-версия остаётся «боевой» (релизы, APK, Windows/Linux), пока
Unity-версия не достигнет паритета по пунктам ниже. Каждый этап —
отдельный PR с проверяемым результатом.

## Этап 0 — каркас (этот коммит) ✅

- Проект Unity 6.3 LTS в `unity/`, открывается из клона, Play работает.
- Code-first бутстрап: сцена пустая, всё строится из кода.
- Одна машина (Bugatti GLB) + её записанный банк звука, физика с
  числами из ТЗ, тестовая прямая + слалом, HUD, сенсорные кнопки.
- Меню редактора: настройка проекта и локальная сборка APK.
- CI-заготовки GameCI (активация + сборка), инструкция по лицензии.

## Этап 1 — картинка и производительность

- URP (Universal Render Pipeline) вместо Built-in: ассет качества,
  три пресета как в Godot (Скорость/Баланс/Красота), тени каскадами.
- Шрифт с кириллицей (Exo2/Inter), русский HUD.
- Замер FPS на реальном телефоне по контрольному маршруту, бюджет
  draw calls/текстур; LOD для машин и пропсов.

## Этап 2 — все машины и звук

- Остальные 4 машины (Mustang из LFS, Audi, Camaro, Mercedes) +
  их банки; каталог с характеристиками 1-в-1 из Godot
  (car_catalog.gd → C# ScriptableObjects/JSON).
- Старт/стоп двигателя, попсы, шины, ветер — паритет vehicle_audio.gd.

## Этап 3 — миры

- RichTown 7×7: перенос генераторов дорог/зданий/пропсов (Blender
  GLB-те же), побережье, Остров-Пальма, мосты, scenic spots.
- Пустынный Каньон и Лес (террейны, MultiMesh → GPU instancing).

## Этап 4 — игра вокруг езды

- Главное меню/гараж/магазин/профиль/карты (паритет 0.3.32:
  скролл, стрелки, 56px), HUD с миникартой и маршрутом,
  визуальный руль, настройки управления.
- Сохранения (профиль, кредиты, машины, кастомизация, рекорды).
- Персонаж и хождение пешком (модель та же, контроллер новый).

## Этап 5 — доставка как раньше

- GameCI: APK + Windows + Linux в каждый релиз, те же имена файлов
  и стабильные ссылки releases/latest.
- Паритет-чеклист пройден → Unity становится основной версией,
  Godot замораживается (не удаляется).

## Этап 6 — онлайн (когда дойдём)

- Тот же Cloudflare-бэкенд (заготовка в репозитории), аккаунты,
  задания, лидеры — по исходному ТЗ.
