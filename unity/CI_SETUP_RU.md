# CI-сборки Unity через GitHub Actions (разовая настройка)

Unity, в отличие от Godot, требует активированную лицензию даже для
сборок на сервере. Для бесплатного тарифа **Unity Personal** это
делается один раз вручную (файл лицензии кладётся в секреты
репозитория). Пароль от аккаунта **никому не отправляйте** — все
секреты вы вносите сами в интерфейсе GitHub.

## Шаги

1. **Аккаунт Unity**: зарегистрируйтесь на unity.com и активируйте
   бесплатную лицензию Unity Personal в Unity Hub на своём компьютере
   (Hub → шестерёнка → Licenses → Add → Get a free personal license).
2. **Запрос файла активации**: в репозитории GitHub откройте
   Actions → workflow **«Unity: request activation file»** →
   Run workflow. После завершения скачайте артефакт — внутри файл
   `Unity_v6000.3.0f1.alf` (имя может отличаться цифрами версии).
3. **Обмен на лицензию**: зайдите на https://license.unity3d.com/manual
   под своим аккаунтом, загрузите `.alf`, скачайте `.ulf`
   (Unity license file).
4. **Секреты репозитория**: GitHub → репозиторий → Settings →
   Secrets and variables → Actions → New repository secret:
   - `UNITY_LICENSE` — **содержимое** файла `.ulf` целиком
     (открыть блокнотом → скопировать всё);
   - `UNITY_EMAIL` — email вашего Unity-аккаунта;
   - `UNITY_PASSWORD` — пароль Unity-аккаунта
     (нужен GameCI чтобы корректно возвращать лицензию после сборки;
     хранится только как зашифрованный секрет GitHub).
5. **Сборка**: Actions → **«Unity: build Android + Windows»** →
   Run workflow. Готовые файлы появятся как артефакты запуска.

Пока секретов нет, workflow сборки просто напишет в Summary, что
нужна активация, и завершится без ошибки.

## Альтернатива без CI

Меню редактора `Nitches → 2. Build Android APK (development)`
собирает APK локально — секреты для этого не нужны вовсе, работает
ваша локальная лицензия из Hub.
