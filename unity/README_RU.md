# Nitches Horizon — Unity-версия (прототип 0.1.0)

С чистого листа на Unity. Godot-версия в этом же репозитории остаётся
рабочей и публикуется как раньше, пока Unity-версия её не догонит
(план — в `MIGRATION_PLAN.md`).

## Что уже умеет прототип

- Загружает настоящую поставленную модель **Bugatti** (GLB) и ставит
  её на самописную аркадную физику: подвеска на лучах, 7 передач с
  числами из вашего ТЗ (6→7 на 403 км/ч), полный привод, дрифт на
  ручнике, N₂O, аэродинамика до ~440 км/ч.
- Настоящий записанный звук двигателя — тот же банк `bugatti_chiron`
  (якоря по оборотам, on/off throttle), без синтезированного тона.
- Тестовый мир из кода: длинная прямая на все передачи, возвратная
  прямая со слаломом, блоки-«дома» с коллизиями.
- Управление: WASD/стрелки + Space (дрифт) + Shift (N₂O) и крупные
  сенсорные кнопки на экране.

Всё собирается из кода при старте (`GameBootstrap`), поэтому сцена
пустая — это нормально.

## Как запустить у себя (один раз)

1. Установите **Unity Hub** и в нём редактор **Unity 6.3 LTS**
   (6000.3.x). При установке редактора отметьте модуль
   **Android Build Support** и внутри него **Android SDK & NDK Tools**
   и **OpenJDK**.
2. Склонируйте/обновите репозиторий и откройте в Unity Hub папку
   **`unity/`** (кнопка Add → выбрать папку `unity` внутри Nitches).
   Первый импорт скачает пакеты (нужен интернет) и займёт несколько
   минут.
3. В редакторе: меню **`Nitches → 1. Setup project`** — создаст сцену,
   пропишет Bundle ID `io.nitches.horizon`, ландшафтную ориентацию,
   ввод «Both» и физику 100 Гц. Если покажет просьбу перезапустить
   редактор — перезапустите (смена режима ввода применяется только так).
4. Нажмите **Play**. Машина, мир, HUD и звук появятся сами.

## Сборка APK

- Быстро и локально: меню **`Nitches → 2. Build Android APK
  (development)`** — APK ляжет в `unity/Builds/Android/`.
- Через GitHub Actions (как Godot-релизы): нужна разовая активация
  лицензии — пошагово в `CI_SETUP_RU.md`.

## Если что-то не заработало

Пришлите мне текст красных ошибок из окна **Console** редактора
(или скриншот) — поправлю код. Известные места первого запуска:

- Пакет `com.unity.cloud.gltfast` не нашёлся: откройте
  `Window → Package Manager → + → Add package by name` и введите
  `com.unity.cloud.gltfast`. Без него не скомпилируется
  `CarModelLoader.cs`.
- Машина — красный «кирпич»: модель не загрузилась (смотрите строку
  статуса слева сверху и Console). Файл должен лежать в
  `Assets/StreamingAssets/Cars/bugatti_chiron_super_sport.glb`;
  пересинхронизировать ассеты: `node scripts/sync-unity-assets.mjs`
  из корня репозитория.
- Клавиатура не работает, кнопки работают: выполните шаг 3 и
  перезапустите редактор.

## Структура

```
unity/
  Assets/Scripts/        весь игровой код прототипа (C#)
  Assets/Editor/         меню Nitches (настройка + сборка APK)
  Assets/StreamingAssets/ модели машин (GLB) и банки звука (WAV)
  Packages/manifest.json пакеты (glTFast, uGUI)
  ProjectSettings/ProjectVersion.txt  версия редактора 6000.3.0f1
```
