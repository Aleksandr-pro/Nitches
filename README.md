# 🏎️ NITCHES HORIZON

ProfitNiche 2026

**Мобильная гонка с открытым миром в духе Forza Horizon** — как CounterFlame для
Counter-Strike, только про фестивальные гонки. Полностью оригинальная фанатская
игра: тропический остров, соперники, чекпоинты, дрифт и нитро. Работает прямо
в браузере телефона и устанавливается на главный экран как приложение (PWA).

> Не аффилирована с Microsoft, Xbox Game Studios, Turn 10 или Playground Games.
> Forza Horizon — товарный знак Microsoft. Здесь только жанровое вдохновение:
> никаких чужих моделей, машин, музыки или названий.

## 🎮 Что уже внутри (v0.1)

- **Открытый остров** ~600×600 м: кольцевая трасса, горы, деревня, фестивальные
  шатры, воздушные шары, закат и океан вокруг — можно срезать по бездорожью
- **Гонка**: 3 круга, 5 соперников с ИИ и «резиновой лентой», 12 чекпоинтов,
  позиция, таблица финиша, рекорд круга (сохраняется)
- **Свободная поездка**: катайся где хочешь, набивай очки дрифта
- **3 машины** с разными характеристиками: Volt GT, Falcon RS, Dune Breaker
- **Аркадная физика**: дрифт с цепочками очков ×8, нитро с пламенем и расширением FOV,
  разное сцепление на асфальте и грунте, столкновения, вибрация на телефоне
- **HUD как в больших гонках**: спидометр, миникарта острова, стрелка к чекпоинту,
  полоса нитро, всплывающие очки дрифта
- **Звук мотора** синтезируется в WebAudio (без аудиофайлов)
- **3 камеры**: погоня / издалека / капот

## 📱 Управление

| Действие | Телефон | ПК |
|---|---|---|
| Газ / тормоз | Кнопки справа | `W` / `S` или стрелки |
| Руль | Кнопки слева ◀ ▶ | `A` / `D` |
| Нитро | ⚡ | `Shift` |
| Дрифт (ручник) | 💨 | `Пробел` |
| Камера | 🎥 | `C` |
| На трассу (респаун) | ⟲ | `R` |
| Пауза | ⏸ | `Esc` |

## 📲 Как установить на телефон как приложение

1. Открой опубликованную ссылку на телефоне.
2. **Android (Chrome)**: меню ⋮ → «Установить приложение» / «Добавить на главный экран».
3. **iPhone (Safari)**: «Поделиться» → «На экран „Домой“».
4. Игра запустится на весь экран горизонтально и будет работать офлайн
   после первого визита.

## 🚀 Запуск для разработки

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # продакшен-сборка в dist/
npm run preview  # предпросмотр сборки
```

## 🗺️ Дорожная карта к «настоящей» мобильной игре

1. **Сейчас**: PWA — играется на любом Android/iPhone без магазинов приложений.
2. **APK / App Store**: обернуть ту же сборку через
   [Capacitor](https://capacitorjs.com) (`npx cap add android`) — код переписывать не надо.
3. **Дальше по фичам**: гироскоп-руль, гараж и тюнинг, смена дня/ночи и погоды,
   скоростные зоны, рекорды прыжков, ещё 2 трассы (город и пустыня),
   мультиплеер-призраки, рекорды в онлайне.

## 🛠️ Технологии

Three.js + Vite, ванильный JS, ноль внешних ассетов — весь мир, машины и текстуры
генерируются кодом, поэтому игра весит ~135 КБ в gzip (вместе с движком)
и тянет даже на слабых телефонах.
