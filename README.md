# 🏎️ NITCHES HORIZON

ProfitNiche 2026

**Мобильная гонка с открытым миром в духе Forza Horizon. 
Полностью оригинальная фанатская игра: тропический остров, соперники, чекпоинты, дрифт и нитро.

> Не аффилирована с Microsoft, Xbox Game Studios, Turn 10, Playground Games или Nissan.
> Forza Horizon — товарный знак Microsoft; Nissan GT-R — товарный знак Nissan.
> Большинство машин собрано процедурным кодом; Mustang Fastback подключён как оптимизированный GLB из Model Inbox.


## 📱 Управление

| Действие | Телефон | ПК |
|---|---|---|
| Газ / тормоз | Кнопки справа | `W` / `S` или стрелки |
| Руль | Вращение руля пальцем (или кнопки ◀ ▶) | `A` / `D` или вращение руля мышью |
| Нитро | ⚡ | `Shift` |
| Дрифт (ручник) | 💨 | `Пробел` |
| Камера | 🎥, свайп по экрану — орбита, щипок — зум, ⌖ — сброс | `C`, мышь — орбита, колесо — зум, `V` — сброс |
| Осмотр машины | 🔍 | `I` |
| На трассу (респаун) 

Установка:

1. Скачай `.apk` по прямой ссылке выше прямо на телефон (Android 7.0+).
2. Открой файл. Если Android попросит — разреши браузеру/файловому менеджеру
   «Установку из неизвестных источников» (это стандартное предупреждение
   для приложений не из Google Play).
3. Нажми «Установить» — игра появится на рабочем столе как обычное приложение:
   на весь экран, горизонтально, работает офлайн.

> Если обновление не ставится поверх прежней версии (у сборок разные CI-ключи подписи) —
> Удали и поставь новую версию
