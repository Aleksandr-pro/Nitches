# 🏎️ NITCHES HORIZON

ProfitNiche 2026

**Мобильная гонка с открытым миром в духе Forza Horizon** — как CounterFlame для
Counter-Strike, только про фестивальные гонки. Полностью оригинальная фанатская
игра: тропический остров, соперники, чекпоинты, дрифт и нитро. Работает прямо
в браузере телефона и устанавливается на главный экран как приложение (PWA).

> Не аффилирована с Microsoft, Xbox Game Studios, Turn 10, Playground Games или Nissan.
> Forza Horizon — товарный знак Microsoft; Nissan GT-R — товарный знак Nissan.
> Большинство машин собрано процедурным кодом; Mustang Fastback подключён как оптимизированный GLB из Model Inbox.

## 📱 Управление

| Действие | Телефон | ПК |
|---|---|---|
| Газ / тормоз | Кнопки справа | `W` / `S` или стрелки |
| Руль | Вращение руля пальцем (или кнопки ◀ ▶) | `A` / `D` или вращение руля мышью |
| Нитро | ⚡ | `Shift` |
| Дрифт (ручник) | 💨 | `Пробел` |
| Камера | 🎥, свайп по экрану — орбита, щипок — зум, ⌖ — сброс | `C`, мышь — орбита, колесо — зум, `V` — сброс |
| Осмотр машины | 🔍 | `I` |
| На трассу (респаун) | ⟲ | `R` |
| Пауза | ⏸ | `Esc` |

## 📱 Android APK — скачать и играть

> ### ⬇️ [Скачать NitchesHorizon-v0.4.0.apk](https://github.com/Aleksandr-pro/Nitches/releases/download/v0.4.0/NitchesHorizon-v0.4.0.apk)
>
> Все версии: [страница релизов](https://github.com/Aleksandr-pro/Nitches/releases)

Установка:

1. Скачай `.apk` по прямой ссылке выше прямо на телефон (Android 7.0+).
2. Открой файл. Если Android попросит — разреши браузеру/файловому менеджеру
   «Установку из неизвестных источников» (это стандартное предупреждение
   для приложений не из Google Play).
3. Нажми «Установить» — игра появится на рабочем столе как обычное приложение:
   на весь экран, горизонтально, работает офлайн.

> Если обновление не ставится поверх прежней версии (у сборок разные CI-ключи подписи) —
> удали старую версию и поставь v0.4.0 заново.

APK собирается автоматически GitHub Actions (`.github/workflows/build-apk.yml`):
Capacitor упаковывает веб-игру в нативное приложение `com.profitniche.nitcheshorizon`.
Своя локальная сборка: `npm run cap:sync` → открыть папку `android/` в Android Studio → Run.

## 📲 iPhone / без APK: установка как PWA

1. Открой опубликованную ссылку на телефоне.
2. **Android (Chrome)**: меню ⋮ → «Установить приложение» / «Добавить на главный экран».
3. **iPhone (Safari)**: «Поделиться» → «На экран „Домой“».
4. Игра запустится на весь экран горизонтально и будет работать офлайн
   после первого визита.

## 🚀 Запуск для разработки

```bash
git lfs install --local
git lfs pull --include="public/assets/models/**" --exclude=""
npm install
npm run dev      # http://localhost:5173
npm run build    # продакшен-сборка в dist/ + проверка LFS-ассетов
npm run preview  # предпросмотр сборки
```

Большие 3D-модели и текстуры хранятся через Git LFS: runtime-`.glb` кладутся в
`public/assets/models/cars/`, редактируемые исходники — в `asset-source/cars/`.
С телефона архивы моделей на 100–200 МБ загружаются не через обычную кнопку
GitHub Upload, а в технический draft-релиз **Model Inbox** на странице Releases;
оттуда их переносят в LFS. Полный конвейер, требования к моделям и запасной план
при исчерпании квоты: [docs/ASSET_PIPELINE.md](docs/ASSET_PIPELINE.md).

## 🗺️ Дорожная карта к «настоящей» мобильной игре

1. ✅ **PWA** — играется на любом Android/iPhone без магазинов приложений.
2. ✅ **Android APK** — Capacitor + автоматическая сборка в GitHub Actions,
   готовый файл — в [релизах](https://github.com/Aleksandr-pro/Nitches/releases).
3. **Google Play**: для публикации нужна подпись стабильным ключом —
   добавьте в секреты репозитория `ANDROID_KEYSTORE_BASE64` и
   `ANDROID_KEYSTORE_PASSWORD` (workflow подхватит их автоматически) и собирайте `.aab`.
4. **Дальше по фичам**: гироскоп-руль, гараж и тюнинг, смена дня/ночи и погоды,
   скоростные зоны, рекорды прыжков, ещё 2 трассы (город и пустыня),
   мультиплеер-призраки, рекорды в онлайне.

## 🛠️ Технологии

Three.js + Vite, ванильный JS. Игровой мир и большинство машин генерируются кодом,
поэтому JS-бандл весит ~198 КБ в gzip (вместе с движком) и тянет даже на слабых
телефонах. Mustang загружается как GLB из Git LFS; для внешних 3D-моделей настроены
проверка реальных байтов при сборке, Blender-конвертация из Model Inbox и чистая
CI-валидация.
