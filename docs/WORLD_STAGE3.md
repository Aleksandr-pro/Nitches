# Этап 3 — фундамент мира 4×4 км (Festival Britain)

Статус: **реализовано как спящий фундамент за фичефлагом**. Играбельной
основой по умолчанию остаётся legacy-карта 640 м; переключение геймплея на
новую карту — задача этапа вертикального среза (этап 5), а не этого этапа.

## Что построено

Все модули лежат в `src/world/` и не зависят от legacy-монолита
`src/main.js` (кроме тонкого Three-адаптера стримера):

| Модуль | Назначение |
|---|---|
| `heightfield.js` | Детерминированное высотное поле 4×4 км: seeded value-noise fBm, горные массивы Lake District / West Highlands, котловина озера ниже уровня воды, Castle Hill, Moorland, выравнивание Festival/Kingsford/деревень, восточное и южное побережья, спад под воду за границей. Тайлы высот 250 м с инклюзивными вершинами (26×26 при 10 м шаге) — швы соседних тайлов совпадают, т.к. зовут один сэмплер. |
| `roadGraph.js` | Чистый дорожный граф: валидация узлов/рёбер, открытая Catmull-Rom дискретизация (~5 м), дуговые длины, Dijkstra по расстоянию/времени, сегменты, `roadPointAt`, ленточная геометрия полотна независимыми квадами (клиппинг по чанкам, треугольники смотрят +Y). |
| `spatialIndex.js` | Равномерный spatial hash (ячейка 50 м) с дедупликацией; точный поиск ближайшей дороги расширяющимся радиусом; индекс коллайдеров: круг, капсула-сегмент, повёрнутый OBB; broadphase + точная дистанция/проникновение. Сканирования всего мира в физическом шаге не требуется. |
| `chunks.js` | Сетка 16×16 = 256 чанков по 250×250 м, конверсии мир↔чанк, планировщик стриминга: радиус загрузки 2, выгрузки 3 (гистерезис против мерцания на границах), очередь по близости, бюджет загрузок за апдейт, LOD-ступени 0/1/2 по чебышёвской дистанции. |
| `festivalBritain.js` | Составная основа карты: 10 районов, 38 узлов и 62 ребра дорог (внешнее A-кольцо, северный маршрут и перевалы, центральные кресты, восточная магистраль, городская основа, грунтовые связи ферм/леса) — суммарно ~46,7 км. Профили высот дорог: сглаживание по дуге ±~95 м, ограничение уклона 14 %, усреднение стыков в узлах и точная сшивка концов без «клиффов» (чередующиеся прямой/обратный Lipschitz-проходы с закреплёнными концами). Террейн подмешивается к высоте полотна внутри коридора и возвращается к сырому рельефу за ~18 м от кромки. Классификация поверхностей: асфальт, брусчатка, бетон, грунт, гравий, трава, вереск, лесная почва, поле, скала, песок, вода. Сериализуемый манифест всех 256 чанков. |
| `meshBuilders.js` | Чистые билдеры геометрии террейн-тайлов (позиции/нормали/UV/вершинные цвета/индексы) и слияние геометрий лент. Тестируется без рендерера. |
| `worldStreamer.js` | Three.js-адаптер: общие материалы, террейн-тайлы 25/12/6 ячеек по LOD, ленты дорог по чанкам с группировкой по поверхности, водная плоскость, бюджетная загрузка/выгрузка с `dispose()` геометрий. |

## Координаты и масштаб

- 1 юнит Three.js = 1 метр; игровые границы `x, z ∈ [-2000, 2000]`.
- +X восток, +Z юг (как на карте сверху).
- Якоря районов: Festival (0, 1250), Kingsford City (1250, −1050),
  Castle (850, −1450), озеро (−1200, −1050), Moor (−100, −1250),
  Farms (−950, 250), East Coast (1650, 200), Forest (1050, 850),
  Airfield (650, 1725), West Highlands (−1550, −250).

## Манифест мира

`public/assets/world/festival-britain/manifest.json` генерируется
детерминированно из кода фундамента (seed 20261025):

```bash
npm run world:manifest   # перегенерировать
npm run world:check      # упасть, если манифест устарел (CI)
```

Схема v1: границы мира, районы, таблица поверхностей (μ и сопротивление
качению), дорожный граф и все 256 чанков со ссылками на дорожные рёбра,
районами и диапазонами высот. На следующих этапах манифест можно отдавать
через R2-каталог ресурсов без смены схемы.

## Фичефлаг и диагностика

В `src/main.js` фундамент создаётся только при включённом флаге:

- URL: `?world=foundation` (опционально `&worldPreview=1` — показать меши;
  корень стримера смещён на −35 м под legacy-карту, чтобы предпросмотр не
  ломал текущий геймплей);
- или `localStorage.setItem('nh_world_foundation', '1')`.

Диагностика для QA: `window.__NH_WORLD__` — `{ enabled, preview, source,
foundation, streamer, stats(), setPreview(bool) }`. Стример обновляется из
`animate()` не чаще 4 раз/с с бюджетом 2 чанка и следует за позицией
игрока; при выключенном флаге ветка — no-op. Физика, коллизии, гонки и
трафик legacy-мира этим этапом не затрагиваются.

## Проверки

- `npm run test:world` — 22 теста (высотное поле, граф, индексы, чанки,
  составная основа, геометрия, Three-стример); включён в общий `npm test`
  (58 тестов).
- Гарантии под тестами: все узлы достижимы от Festival; уклон полотна
  ≤ 14 % между соседними сэмплами; высоты стыков в узлах совпадают точно;
  `heightAt` на осевой линии дороги равен высоте профиля (< 0,05 м);
  манифест сериализуется в 256 чанков.

## Сознательно не входит в этап 3

- Переезд геймплея/физики/трафика на новую карту, спавны и гонки — этап 5.
- Здания, деревья, пропсы и их коллайдеры (`ColliderIndex` готов, но пуст)
  — этап 4 (процедурные паки) и далее.
- Мосты/туннели: дороги пока следуют сглаженному рельефу; озеро огибается
  по восточному берегу.
- Текстуры террейна/дорог: пока вершинные цвета и плоские материалы.
- Камера/туман legacy-мира рассчитаны на 640 м (far 2000, туман до 880 м):
  для играбельного предпросмотра всей карты их поднимут на этапе среза.
