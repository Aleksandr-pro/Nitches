# Nitches Horizon — план большой британской карты, Physics v2 и облачных ассетов

Статус: **архитектурный план согласован по ключевым решениям**:

- сеттинг — оригинальная Британия в духе Forza Horizon 4, без копирования карты,
  моделей, логотипов и названий из FH4;
- размер игрового мира — **4×4 км**;
- физика — **simcade**: настоящие масса, момент, передачи и сопротивление,
  но с дружелюбными ассистентами для телефона;
- модели — **гибрид**: сначала процедурные GLB-паки в едином стиле, затем
  внешние hero-модели владельца постепенно заменяют процедурные версии;
- уже встроенные в APK модели остаются в APK, новый внешний контент
  публикуется через Cloudflare R2.

Документ является планом этапов, а не обещанием сделать все пункты одним PR.
Каждый этап должен заканчиваться тестами, чистой CI-сборкой, проверкой на
Android и отдельным отчётом.

## 1. Что показал аудит текущего кода

### Мир

- Текущий остров — одна плоскость `640×640 м` (`168×168` сегментов).
- Главная дорога — один замкнутый сплайн; дополнительные дороги уже есть,
  но вся логика гонки, соперников, респавна и части мира завязана на
  `pointAtS()` главной трассы.
- Главная дорога имеет ширину **11,2 м**, деревенские — около **7,4 м**.
  Для британской B‑дороги 11,2 м слишком широко: машина визуально кажется
  маленькой даже при реальных размерах кузова.
- Коллайдеры — один плоский массив кругов; поиск ближайшей точки дороги и
  проверка коллизий не масштабируются на тысячи объектов и 16 км².
- Весь мир создаётся при старте. Для 4×4 км нужны чанки, пространственные
  индексы, LOD и инстансинг, а не простое увеличение плоскости.

### Автомобиль

- У машин уже есть масса, мощность, база, центр масс, `dragArea`, `tireMu`.
- Но передача выбирается по жёстким порогам скорости, RPM в основном
  рисуется из положения внутри передачи, а тяга считается как
  `min(mass × launchAccel × gearFactor, power / speed)`.
- Нет настоящей кривой момента, передаточных чисел, радиуса колеса в тяге,
  времени переключения, сцепления при старте и полноценного автомата
  D/N/R.
- Газ и тормоз на входе бинарные, затем лишь сглаживаются рампой. Тормоз и
  задний ход разделяются порогом скорости, поэтому переход ощущается грубо.
- Шинная bicycle‑модель, перенос веса и круг сцепления уже дают хорошую базу;
  переписывать нужно прежде всего силовую установку и педали.

### Интерфейс

- В HUD и меню массово используются emoji. Нужна единая inline SVG‑система с
  `currentColor`, одинаковой толщиной линий и доступными подписями.

## 2. Можно ли просто загружать текстуры и папки в Cloudflare

Короткий ответ: **нет, одной загрузки файлов и создания папок недостаточно**.
В R2 «папка» — это только префикс ключа объекта. Игра не сканирует bucket и
сама не догадывается, что делать с новым PNG.

### Что работает уже сейчас

Текущий клиент умеет:

1. скачать `manifests/current.json`;
2. по указателю скачать проверенный версионированный каталог;
3. найти в каталоге ассет и его GLB;
4. проверить размер и SHA‑256;
5. сохранить GLB в IndexedDB;
6. распарсить самодостаточный GLB и поставить его через адаптер.

Поэтому рабочий путь на сегодня:

```text
модель + встроенные текстуры
  -> один самодостаточный .glb
  -> неизменяемый ключ вида category/asset_id/version/model-<sha256>.glb
  -> запись в версионированном manifest.json
  -> проверка размера, SHA-256, bounds, pivot, LOD и collider
  -> загрузка GLB и manifest в R2
  -> manifests/current.json последним
```

Если загрузить только GLB, только текстуру или создать новую папку, но не
обновить каталог и расстановку мира, игра объект не увидит.

### Текстуры внутри GLB — основной путь

Для моделей используем glTF PBR:

| Карта | Назначение | Цветовое пространство |
|---|---|---|
| `baseColor` | цвет/альбедо | sRGB |
| `normal` | рельеф | linear, tangent space |
| `metallicRoughness` | G = roughness, B = metallic | linear |
| `occlusion` | R = AO | linear |
| `emissive` | свечение | sRGB |

Правила первого поколения ассетов:

- текстуры встроены в GLB; внешние URI запрещены;
- размеры — степени двойки; hero‑объекты до 2048², обычные пропсы 512²–1024²;
- одинаковые материалы и атласы переиспользуются внутри пака;
- Draco/Meshopt/KTX2 не публикуем, пока соответствующие декодеры не будут
  добавлены и измерены на Android;
- исходные ZIP/Blend/FBX остаются в Model Inbox/приватном источнике, а не в
  публичном runtime bucket.

### Отдельные текстуры и материалы — следующий слой

Для дорог, террейна и повторяющихся поверхностей добавим material packs:

```text
materials/<material_id>/<version>/
  albedo-<sha256>.png|jpg|ktx2
  normal-<sha256>.png|jpg|ktx2
  roughness-<sha256>.png|jpg|ktx2
```

Но сначала клиент должен получить:

- роли файлов `albedo`, `normal`, `roughness`, `ao`, `emissive`;
- `colorSpace`, `wrap`, `repeat`, `anisotropy`, `alphaMode`;
- загрузчик текстур и кэш уже созданных `THREE.Texture/Material`;
- позже KTX2/Basis и fallback для устройств без нужных форматов сжатия.

### Как объект попадает на карту

Каталог отвечает на вопрос «какие ассеты существуют». Для мира нужен второй
тип данных — world chunk:

```json
{
  "chunk": [4, 9],
  "placements": [
    {
      "assetId": "building_stone_cottage_002",
      "adapter": "static-prop",
      "position": [812.4, 0, -640.2],
      "rotationY": 1.5708,
      "scale": 1
    }
  ]
}
```

После появления world manifest новые объекты поддерживаемых типов можно
будет публиковать без нового APK: GLB → каталог → chunk placement → pointer.
Новый тип поведения (транспорт, открывающиеся ворота, поезд, разрушаемый
объект) по-прежнему требует кодового адаптера.

## 3. Целевая карта 4×4 км

Мир остаётся в реальном масштабе: **1 единица Three.js = 1 метр**.
Игровая область: `x,z ∈ [-2000, 2000]`. Это 16 км² — примерно в 39 раз
больше текущей площади.

Рабочее имя региона — **Festival Britain / Долина фестиваля**. Все названия и
компоновка оригинальные.

| Район | Примерный центр | Характер |
|---|---:|---|
| Festival Vale | `(0, 1250)` | главная площадка, сцена, гараж, старты, широкая долина |
| Kingsford City | `(1250, -1050)` | плотный город, набережная, старые улицы, кольцевые развязки |
| Castle Hill | `(850, -1450)` | замок над городом, серпантин, смотровая площадка |
| Lake District & Fells | `(-1200, -1050)` | озеро, горы, дамба, узкие перевалы |
| Moorland | `(-100, -1250)` | вересковые холмы, быстрые A‑дороги, ветряки |
| Cotswold Farms | `(-950, 250)` | каменные деревни, фермы, поля, сухие каменные стены |
| East Coast Village | `(1650, 200)` | порт, пляж, маяк, прибрежная дорога |
| Forest & Quarry | `(1050, 850)` | лес, грунтовые трассы, карьер и индустриальная зона |
| South Beach & Airfield | `(650, 1725)` | пляжные гонки, взлётная полоса и drag‑прямая |
| West Highlands | `(-1550, -250)` | скалы, виадук, ветроферма, технические дороги |

### Дорожная сеть

Целевой объём первого полного релиза карты:

- 50–70 км проходимых дорог всех типов;
- внешнее A‑кольцо и 3–4 поперечных маршрута;
- южно‑северная магистраль к городу;
- городская сетка и минимум 4 круговых перекрёстка;
- 2 горных перевала и один длинный прибрежный маршрут;
- грунтовые связки к фермам, карьеру и лесным трассам;
- минимум один мост/виадук и один короткий тоннель;
- маршруты для трафика и гонок строятся по графу, а не одному сплайну.

Первый сезон визуально — позднее лето/ранняя осень. Сезоны FH4 не
копируются и не делаются первой версией: позже можно менять палитры листвы,
материалы террейна, освещение и сцепление без дублирования всей геометрии.

## 4. Стандарты масштаба

Машину не увеличиваем искусственно: спортивный автомобиль остаётся длиной
примерно 4,4–4,7 м и шириной 1,8–2,0 м. Ощущение масштаба исправляем
дорогами, зданиями, камерой и скоростью звука/FOV.

| Элемент | Стандарт |
|---|---:|
| Полоса A‑дороги/магистрали | 3,65 м |
| Двухполосная A‑дорога | 7,3 м + обочины |
| B‑дорога | 5,5–6,5 м |
| Однополосная сельская дорога | 3,0–3,7 м + passing places |
| Городская улица | 6–9 м + тротуары 1,8–3 м |
| Грунтовая дорога | 3,5–5 м |
| Этаж здания | 2,9–3,2 м |
| Дверной проём | 2,05 м |
| Уличный фонарь | 6–10 м |
| Взрослое дерево | 7–15 м |
| Сухая каменная стена | 1,05–1,3 м |
| Телеграфный столб | 8–10 м |

Дополнительно для ощущения скорости:

- chase‑камера с дистанцией и FOV, зависящими от скорости плавно, без рывков;
- корректная частота дорожной разметки, столбов и стен;
- звук двигателя из реальных RPM/нагрузки, а не одной скорости;
- вибрация/наклон кузова от продольного и бокового ускорения.

## 5. Архитектура стриминга мира

### Чанки

- Сетка `16×16`, размер чанка **250×250 м**.
- Ближнее кольцо: полная геометрия и коллайдеры.
- Среднее кольцо: LOD1/LOD2, только крупные коллайдеры около дорог.
- Дальний план: террейн низкой детализации, силуэты гор/города/замка.
- Гистерезис загрузки/выгрузки, чтобы чанки не мигали на границе.
- Дисковый R2‑кэш не удаляется при выгрузке сцены; освобождаются только
  экземпляры и, при давлении памяти, распарсенные шаблоны.

### Данные

```text
world/
  world.json                 # версия мира, границы, список чанков
  height/                    # heightfield-тайлы
  roads/road-graph.json      # узлы, сплайны, полосы, поверхности
  chunks/<cx>_<cz>.json       # placements и локальные игровые объекты
  routes/                    # гоночные маршруты и трафик
```

Для дорог и террейна строятся пространственные индексы; полный перебор всех
сэмплов и коллайдеров на каждый физический шаг запрещён. Коллайдеры делятся
на круги, OBB и отрезки стен/зданий и хранятся в spatial hash по чанкам.

### Бюджеты Android

Целевые ориентиры среднего телефона (уточняются профилированием):

- 30 FPS на среднем устройстве, 60 FPS на сильном при сниженной плотности;
- не более ~250–350 draw calls в обычной сцене;
- не более ~700 тыс. видимых треугольников в городе, меньше в сельской зоне;
- один направленный свет с теневой камерой, следующей за игроком;
- повторяющиеся деревья, стены, столбы и трава — `InstancedMesh`;
- каждый hero‑ассет имеет LOD0/LOD1/LOD2 или impostor;
- загрузка чанка не блокирует кадр: бюджет парсинга/инстансинга на кадр.

### 6.6 Транспорт

Игровые автомобили добавляются по существующему vehicle‑контракту: метры,
ось и земля в origin, передок `+Z`, отдельные вращающиеся колёса, материалы
кузова/стекла/шин и полные specs для Physics v2.

Для трафика нужны отдельные дешёвые модели (3–12k tris, без салона):

- hatchback, estate, SUV, van, box truck, bus, tractor, classic roadster;
- 3–5 цветов на модель через material tint;
- фары/стопы emissive, простые колёса, OBB‑коллайдер.

## 7. Physics v2 — simcade

### 7.1 Данные автомобиля

Каждый автомобиль получает:

```js
{
  massKg,
  dimensionsM: { length, width, height },
  wheelbaseM, trackFrontM, trackRearM, wheelRadiusM,
  cgToFrontM, cgHeightM,
  engine: {
    idleRpm, redlineRpm, limiterRpm,
    torqueCurveNm: [[rpm, Nm], ...],
    engineBrakeNm,
  },
  gearbox: {
    ratios: [...], reverseRatio, finalDrive,
    shiftUpMs, shiftDownMs, clutchMs,
  },
  drivetrain: { frontBias, efficiency },
  brakes: { maxTorqueNm, frontBias, abs },
  aero: { dragAreaM2, downforce },
  tires: { mu, loadSensitivity, rollingResistance },
}
```

`topSpeed` перестаёт быть главным ограничителем: максималка возникает из
передачи, отсечки, мощности и сопротивления. Отдельный электронный лимитер
допустим только там, где он задан автомобилю.

### 7.2 Разгон

Для каждого физического подшага:

```text
wheelRpm = |u| / wheelRadius * 60 / (2π)
engineRpm = wheelRpm * gearRatio * finalDrive   (при замкнутом сцеплении)
engineTorque = torqueCurve(engineRpm) * throttle
wheelTorque = engineTorque * gearRatio * finalDrive * efficiency
driveForce = wheelTorque / wheelRadius
resistance = 0.5 * rho * dragArea * u*|u|
           + rollingResistance * normalLoad
           + mass * g * slope
```

Отсюда ускорение естественно велико на низших передачах и падает с ростом
скорости. На старте добавляются пробуксовка сцепления и ограничение по
продольному сцеплению шин; traction control профиля Arcade/Sport не даёт
бесконечно шлифовать, Drift ослабляет помощь.

Автомат:

- повышает передачу у красной зоны с учётом газа;
- понижает при падении RPM и kickdown при резком газе;
- на время переключения снижает момент;
- не переключается туда‑сюда из‑за гистерезиса;
- звук и тахометр используют настоящий `engineRpm`.

### 7.3 Тормоз и задний ход

Состояния селектора: `D`, `N`, `R`.

- В `D` педаль тормоза создаёт тормозной момент по осям с bias и ABS.
- Когда скорость почти ноль и педаль продолжает удерживаться заданное
  короткое время, селектор переходит в `R`, та же педаль становится газом
  задней передачи в мобильной схеме управления.
- В `R` педаль газа сначала тормозит движение назад и у нуля возвращает
  селектор в `D`.
- Задняя передача имеет собственный момент, отсечку и максимальную скорость
  примерно 8–12 м/с в зависимости от автомобиля.
- Стоп‑сигналы загораются от тормозного момента, фонари заднего хода — от `R`.

### 7.4 Ввод

- Клавиатура остаётся бинарной, но рампы газа/тормоза настраиваются отдельно
  для нажатия и отпускания.
- Сенсорные педали получают аналоговую глубину: касание и вертикальное
  движение пальца внутри педали меняют значение 0..1.
- Кривые педалей: небольшая мёртвая зона, затем прогрессивный отклик; газ не
  обязан быть линейным по силе, но должен быть предсказуемым по педали.

### 7.5 Калибровочные тесты

Для каждого автомобиля автоматизируются:

- 0–100 км/ч на сухом асфальте;
- 100–200 км/ч, если автомобиль способен;
- максимальная скорость на длинной прямой;
- 100–0 км/ч и тормозной путь;
- старт в подъём, откат и задний ход;
- отсутствие NaN, бесконечной пробуксовки и смены передач на месте;
- одинаковый результат при 30/60/120 FPS за счёт фиксированных подшагов.

## 10. Что присылать владельцу проекта для внешних моделей

Сначала наиболее полезны hero‑модели, которые трудно сделать процедурно
красиво:

1. замок и маяк;
2. церковь, паб, каменные коттеджи и городские фасады;
3. каменный мост и виадук;
4. трактор, автобус, фургон и грузовик для трафика;
5. качественные деревья/кусты с LOD;
6. новые игровые автомобили.

Для каждой модели нужны: источник в Model Inbox, метры, `+Y` вверх, pivot на
земле по центру основания (для автомобилей — отдельный контракт), разумное
число материалов, текстуры и, если есть, LOD. Конвертация всё равно проверит
масштаб, оси, нормали, материалы, число треугольников и создаст runtime GLB,
hash, bounds и collider. Просто класть неизвестные файлы в публичный R2 не
нужно.
